## Rules (keep for the next refresh)
- `price` = cost of ONE generation at the settings the app sends when the user changes nothing
  (= `buildPayload` defaults; optional params at their default are NOT sent, so the API default applies).
  Compute it from the page's pricing `formula` × `discount_rate` / 100; `base_price` is in millionths of a dollar.
- Video-edit and avatar models priced by input duration (`get_duration(...)` in the formula) use the page's
  "starts at" price (`base_price` × discount).
- Every optional param default must equal the public-schema default (audit enforces).
- `price` is the picker label and the fallback. The estimate, each task's `price` and log totals come from the
  model's formula evaluated on the payload actually sent (`src/lib/pricing.js` + `src/lib/priceFormula.js`, a safe
  JSONata-subset evaluator; omitted fields take the schema defaults stored in the table). `node scripts/test-pricing.mjs`
  checks real formulas and that every formula reproduces its registry `price` at default settings.
  Input-length formulas (`get_duration`) use the input's duration read from media metadata
  (`src/lib/mediaDuration.js`); each clip is clamped to the formula's min/max, clips sum (or take the max with
  `aggregate="max"`), capped at `total`. Live-billed 2026-10-20: GPT Image 2.0 low/2K, Nano Banana 2.1 2K and
  FLUX 3 Video Edit (5.06 s input → 6 s billed) all charged exactly the estimate.

## How to rerun
1. `node scripts/wavespeed-model-data.mjs --out=<dir> [--targets=<targets.json>]` — ~20 s for every registry model:
   schema, pricing (base, discount, formula), audit issues, price drift; one JSON per model.
   Sitemap of all WaveSpeed models: `https://wavespeed.ai/model-sitemap.xml` (newest first).
2. Formula evaluation and new-entry drafting: Sonnet 5.5 agents in lanes (fast-agent-run method); each proposal is
   validated with the audit's `compare()` before it is stored. Code applies the result (single writer).
3. `node scripts/audit-wavespeed-models.mjs` must report 0 unavailable / 0 mismatches.
4. Regenerate the pricing table: add `--pricing=src/config/modelPricing.js` to step 1, then `node scripts/test-pricing.mjs`.
